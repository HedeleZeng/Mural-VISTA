# Mural-VISTA
**Mural cell-Vessel Interaction and Single-cell Topo-morphology Analysis**
A tool for mural cell-vessel interaction assessment and multiscale single-cell topo-morphological analysis

# v1.0.0 (260726) 

First release for the preprint

# v2.0.0 (261006) 

1. Refined the cell body extraction process to prevent underestimation caused by failed mesh hole filling in isolated components.
2. Added the "Branch tree max length (rooted)" parameter to calculate the maximum root-to-tip path length of the secondary-process tree.
3. Introduced a napari viewer in the GUI version for structural reference.
4. Optimized the GUI processing logic to reduce freezing and unexpected crashes.
